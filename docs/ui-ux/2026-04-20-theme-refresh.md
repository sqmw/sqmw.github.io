# 2026-04-20 主题与项目卡片视觉优化

## 背景

首页已经具备项目仪表盘雏形，但在深色主题下存在色调不统一、头部邮箱高亮突兀、项目操作按钮权重偏高、右侧榜单拥挤等问题。

## 调整目标

- 统一全局冷灰色阶，减少暖色背景和卡片深色之间的冲突。
- 降低 Header 的视觉噪音，让标题、说明和控制按钮更稳定。
- 弱化次要按钮和语言筛选标签，突出项目标题与描述。
- 增加右侧榜单列表项的留白和对齐稳定性。
- 将主要控件圆角收敛到 `8px` 以内，保持开发者仪表盘风格。

## 关键改动

- `style.css`：更新 light/dark 主题变量，新增 `--surface-subtle`，统一背景、卡片、边框、阴影色阶。
- `style.css`：Header 背景改为冷灰渐变与轻量网格纹理，邮箱后缀不再形成突兀块感。
- `style.css`：筛选 chip、ghost button、项目操作按钮改为更轻的 outline/弱填充状态。
- `style.css`：项目卡片 hover、描述行高、项目标题权重、Star 数据徽章做层级调整。
- `style.css`：侧栏榜单增加 `gap`、`padding`、`line-height` 和 meta 最小宽度，改善拥挤感。
- `style.css`：Header 邮箱后缀显式清除通用 `.highlight` 背景，避免出现误伤色块。
- `style.css`：搜索框和筛选区增加垂直间距，区分搜索与筛选两类动作。
- `style.css`：项目操作按钮默认改为浅色弱填充和透明边框，hover 时再强化边界和品牌色。

## 回归检查

1. 打开 `index.html`。
2. 切换 light/dark 主题，确认背景、Header、卡片色阶统一。
3. 检查项目卡片：标题最突出，描述次之，`文档 / 统计 / 趋势` 按钮不抢主视觉。
4. 检查右侧热门项目和趋势榜：列表行距更宽，星标或趋势值右侧对齐稳定。
5. 检查移动端宽度：Header 控件、项目操作按钮和筛选 chip 不溢出。
